🎯 Objetivo da Sessão

Adicionar quatro funcionalidades interconectadas ao Explainer:

  1. Click na conversa → histórico: exibir mensagens salvas ao selecionar uma conversa na sidebar
  2. ReAct com DeepSeek + pi agent: loop de reasoning com tool calling para tarefas que precisam ler arquivos ou buscar contexto
  3. Geração direta + botão copiar: resposta direta com DeepSeek para tarefas que não envolvem leitura de arquivos
  4. Classificação inteligente: o sistema decide automaticamente se a entrada é conversa, tarefa-com-leitura ou tarefa-sem-leitura

🏗️ Arquitetura Final

Fluxo de classificação

Usuário digita → sendChatMessage() → POST /api/chat → classifyIntent()
  ├─ "conversation" → sugere iniciar voz (WebRTC + OpenAI Realtime)
  ├─ "task_without_reading" → deepseekChat() → resposta direta + CopyButton
  └─ "task_with_reading" → deepseekReasoner() + tools → SSE ReAct stream
       ├─ tool_call → executa ferramenta (search_source, read_source_file, etc.)
       ├─ dispatch_pi_agent → pi agent async (read-only) + polling 180s
       └─ answer → resposta final com CopyButton
